# Python 学习笔记

## 简介
这个仓库包含了我在学习 Python 过程中整理的笔记、代码示例和重要概念。主要基于《流畅的 Python》和《Python 3 面向对象编程》等优秀教材，涵盖了从基础语法到高级特性的多个方面。

## 学习资源

### 书籍
- 《流畅的 Python》(Fluent Python) - Luciano Ramalho
- 《Python 3 面向对象编程》(Python 3 Object-Oriented Programming)

## 笔记内容

### 《流畅的 Python》笔记
1. [Python 数据模型](Books/流畅的Python/01.Python数据模型.ipynb) - 特殊方法、魔术方法、对象表示
2. [序列构成的数组](Books/流畅的Python/02.序列构成的数组.ipynb) - 列表推导式、生成器表达式、元组解包
3. [字典与集合](Books/流畅的Python/03.字典与集合.ipynb) - 映射类型、散列表、可散列类型
4. [文本和字节序列](Books/流畅的Python/04.文本和字节序列.ipynb) - 字符编码、Unicode、二进制序列
5. [一等函数](Books/流畅的Python/05.一等函数.ipynb) - 函数对象、高阶函数、匿名函数
7. [函数装饰器和闭包](Books/流畅的Python/07.函数装饰器和闭包.ipynb) - 闭包原理、装饰器模式
8. [对象引用、可变性和垃圾回收](Books/流畅的Python/08.对象引用、可变性和垃圾回收.ipynb) - 变量引用、不可变性、弱引用
9. [符合 Python 风格的对象](Books/流畅的Python/09.符合Python风格的对象.ipynb) - 对象表示形式、格式化、特性属性

## 特点
- 包含丰富的代码示例和输出结果
- 每章总结有关键概念图解
- Jupyter Notebook 格式，便于互动学习和执行代码
- 重点突出 Python 的特性和最佳实践

## 如何使用

1. 克隆仓库到本地
```bash
git clone [仓库地址]
```

2. 安装依赖
```bash
pip install jupyter notebook numpy pandas
```

3. 启动 Jupyter Notebook
```bash
jupyter notebook
```

4. 按照学习进度浏览相应章节的笔记
